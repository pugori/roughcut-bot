## 2. 1단계: 프로필 학습 및 저작권/클레임 방지 사양

### 2.1. 입력 사양
1. **프로필 이름 (`profile_name`)**: 사용자가 본인 목록에서 구분하기 위한 임의의 식별 라벨 (예: "우리형 하이텐션", "양망두 토크", "게임용" 등 자유 텍스트).
2. **치지직 방송 채널 링크 (`chzzk_channel_url`, 선택/참고용)**: 치지직 채널 주소.
3. **솔로 방송 유튜브 링크 3개**: 스트리머 단독 방송 편집본 (1회성 분석용 링크).
4. **합방/콜라보 유튜브 링크 3개**: 게스트와 함께한 대화형 편집본 (1회성 분석용 링크).

### 2.2. 저작권/퍼블리시티권 클레임 원천 차단 설계
- **개인 계정 격리 저장 (Private User Sandbox)**:
  - 사용자가 생성한 프로필은 **오직 해당 사용자의 개인 계정/로컬 PC에만 비공개로 보관**되며 타인에게 공유/노출되지 않습니다.
  - 외부인이 저작권이나 퍼블리시티권 침해를 주장할 법적 명분을 원천 차단합니다.
- **유튜브 링크 6개는 영구 저장하지 않음**: 프로필 계산에 1회성 소모 후 링크 자체는 폐기.
- **기존 방식의 그래프 유사도 러프컷 프로필 데이터만 DB에 영구 저장**:
  - `profile_name`: 사용자가 지정한 식별 라벨
  - `motif_template`: 32-point 정규화된 텐션 빌드업/클라이맥스 곡선 템플릿
  - `avg_shot_length`: 솔로 및 합방의 평균 컷 지속 시간 (초)
  - `tension_interval`: 지배적 텐션 피크 주기 (기본 45.0s)
  - `silence_tolerance`: 무음 임계 시간 (기본 0.8s ~ 1.2s)
  - `highlight_rms_threshold`: 하이라이트 컷팅 z-score 기준치 (기본 0.95 ~ 1.10)
  - `custom_vocab`: 형태소 분석으로 추출된 채널 전용 밈, 게임용어, 어휘 목록

```json
{
```

### 3.2. NLE 미디어 매칭 및 다빈치 리졸브 필수 강제 규칙
1. **로컬 툴**:
   - 사용자가 PC에서 선택한 실제 파일명과 경로를 FFprobe로 추출하여 XML에 정확히 매핑.
   - 프리미어/리졸브로 드래그 시 3초 만에 무손실 자동 연결(Auto-Relink).
2. **디스코드 봇**:
   - 치지직 메타데이터로 `[방송날짜]_[방송제목].xml` 생성 (예: `20260826_생방송_합방.xml`).
   - **다빈치 리졸브 미디어 오프라인 방지 필수 강제 안내**:
     > ⚠️ **[다빈치 리졸브 필수]** 다운로드받으신 영상 파일명을 생성된 XML과 동일하게 **`[방송날짜]_[방송제목].mp4`로 반드시 변경**해 주세요. 파일명이 다르면 다빈치 리졸브에서 영상을 인식하지 못합니다!

## 6. 데이터베이스 스키마 설계 (SQLite DDL)

```sql
-- 1. 사용자 등록 프로필 테이블 (개인 계정 격리)
CREATE TABLE IF NOT EXISTS user_profiles (
    profile_id TEXT PRIMARY KEY,
    discord_user_id INTEGER NOT NULL,
    profile_name TEXT NOT NULL,         -- 사용자가 정한 임의의 이름 (목록 표시용)
    chzzk_channel_url TEXT DEFAULT '',
    solo_profile_json TEXT NOT NULL,    -- 32-point 모티프, ASL 등 솔로 프로필 JSON
    collab_profile_json TEXT NOT NULL,  -- 합방 프로필 JSON
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_up_user ON user_profiles(discord_user_id);

-- 2. 사용자 크레딧 잔액 테이블
CREATE TABLE IF NOT EXISTS user_credits (
    discord_user_id INTEGER PRIMARY KEY,
    credits INTEGER NOT NULL DEFAULT 0,
    total_charged INTEGER NOT NULL DEFAULT 0,
    total_used INTEGER NOT NULL DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 3. 크레딧 입출금 트랜잭션 기록 테이블
CREATE TABLE IF NOT EXISTS credit_transactions (
    tx_id INTEGER PRIMARY KEY AUTOINCREMENT,
    discord_user_id INTEGER NOT NULL,
    amount INTEGER NOT NULL,            -- 양수: 충전/지급, 음수: 차감
    balance_after INTEGER NOT NULL,     -- 거래 후 잔액
    reason TEXT NOT NULL,               -- 사유 ("가편집 분석", "관리자 충전", "웹 결제")
    order_id TEXT DEFAULT '',           -- 결제 주문번호
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 4. 일일 사용량 추적 테이블 (무료/유료 구분)
CREATE TABLE IF NOT EXISTS daily_usage_logs (
    log_id INTEGER PRIMARY KEY AUTOINCREMENT,
    discord_user_id INTEGER NOT NULL,
    usage_date TEXT NOT NULL,           -- YYYY-MM-DD
    is_free_quota INTEGER NOT NULL,     -- 1: 당일 무료 2회 슬롯, 0: 크레딧 사용 슬롯
    video_no TEXT DEFAULT '',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_usage_user_date ON daily_usage_logs(discord_user_id, usage_date);
```
