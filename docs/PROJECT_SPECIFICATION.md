## 1. 프로그램 개요 및 제품 이원화 전략 (Overview & Product Tier Strategy)

- **개요:** 인터넷 방송 플랫폼(치지직, 아프리카TV, 트위치, 유튜브 등)의 4~10시간 장시간 생방송 다시보기(VOD)를 분석하여, 불필요한 침묵·로딩·대기 구간을 자동으로 잘라내고(Rough Cut), 스트리머와 게스트의 발화를 감지해 트랙별로 분리된 영상 편집기용 타임라인 파일(XML)을 생성하는 소프트웨어입니다.
- **목적:** 가편집(무음 자르기) 및 합방 자막 트랙 분리 작업에 소모되는 편집자의 단순 반복 노동 시간을 70% 이상 단축하고, 프리미어 프로 및 다빈치 리졸브로 즉시 3초 만에 가져와 본편집을 시작할 수 있도록 지원합니다.

## 2. 1단계: 스트리머 발화 프로필 생성 (Profile Calibration)

### 2.1. 프로필 등록 시 입력 데이터 사양
1. **`프로필 이름 (Label)`**:
   - 사용자가 본인 목록에서 구분하기 위해 자유롭게 정하는 임의의 식별명 (예: "우리형 하이텐션", "양망두 토크용", "게임합방용" 등 자유 텍스트). 시스템 내부 로직에는 영향 없음.
2. **`치지직 채널 링크 (선택/참고용)`**:
   - 치지직 방송 채널 주소.
3. **`솔로 방송 유튜브 링크 3개`**:
   - 스트리머 단독 방송 편집본 3개 링크 (1회성 분석용 링크, 분석 완료 후 링크 자체는 폐기).
4. **`합방/콜라보 유튜브 링크 3개`**:
   - 게스트와 함께한 대화형 편집본 3개 링크 (1회성 분석용 링크, 분석 완료 후 링크 자체는 폐기).

### 2.2. 저작권/클레임 방지 및 DB 영구 저장 사양
- **외부 공유 배제 & 개인 계정 격리 (Private Sandbox)**:
  - 생성된 프로필은 플랫폼 전체에 공개/배포되지 않고, **오직 해당 사용자의 개인 계정/로컬 PC에만 비공개로 보관**되어 타인이나 외부인의 저작권/퍼블리시티권 클레임을 원천 차단합니다.
- **기존 방식의 그래프 유사도 러프컷 프로필 데이터만 영구 저장**:
  - `profile_name`: 사용자가 지정한 식별 라벨
  - `motif_template`: 32-point 정규화된 텐션 빌드업/클라이맥스 곡선 템플릿
  - `avg_shot_length`: 솔로 및 합방의 평균 컷 지속 시간 (초)
  - `tension_interval`: 지배적 텐션 피크 주기 (기본 45.0s)
  - `silence_tolerance`: 무음 임계 시간 (기본 0.8s ~ 1.2s)
  - `highlight_rms_threshold`: 하이라이트 컷팅 z-score 기준치 (기본 0.95 ~ 1.10)
  - `custom_vocab`: 형태소 분석으로 추출된 채널 전용 밈, 게임용어, 어휘 목록

## 3. 2단계: 가편집 실행 및 2-Step 선택 인터랙션 (VOD Execution)

특정 채널에 프로필이 강제 고정되지 않고, **어떤 영상이든 사용자가 등록해 둔 프로필 목록 중 하나를 선택하고 ➔ 솔로/합방 버튼을 눌러 실행**하는 직관적인 2단계 워크플로우를 제공합니다:

```text
[1. 사용자가 VOD 영상 지정 (/가편집 링크 또는 로컬 파일 드래그앤드롭)]
                           │
                           ▼
          [등록된 프로필 존재 여부 확인]
          ┌────────────────┴────────────────┐
          ▼                                 ▼
   [등록된 프로필 0개]              [등록된 프로필 1개 이상]
   - 임의 프로필로 돌리지 않음       - [Step 1: 프로필 선택 메뉴 노출]
     (오작동/사고 방지 차단)           ┌──────────────────────────────────┐
   - 등록 안내 메시지 출력:            │  적용할 프로필 선택 (드롭다운)   │
     "⚠️ 등록된 프로필이 없습니다.     │  [ 1. 우리형 하이텐션 ]          │
      먼저 프로필을 등록해 주세요."    │  [ 2. 양망두 토크형 ]            │
                                       └──────────────────────────────────┘
                                                     │ (예: '양망두 토크형' 선택)
                                                     ▼
                                     - [Step 2: 방송 유형 선택 버튼 노출]
                                       ┌──────────────────────────────────┐
                                       │  [ 🎤 솔로 방송 모드 ]           │
                                       │  [ 👥 합방 / 콜라보 모드 ]       │
                                       └──────────────────────────────────┘
                                                     │ (예: '합방 모드' 클릭)
                                                     ▼
                                     - [Step 3: 최종 선택된 프로필 & 모드로 가편집 실행!]
```

- **생성 파일:**
  1. `[동영상파일명].xml`: 영상 컷팅 및 화자별 자막 트랙이 배치된 FCP7 XML 시퀀스 파일
  2. `[동영상파일명].srt`: 전체 타임스탬프가 동기화된 보조 자막 파일

### [편집기 미디어 연동 및 파일명 매칭 규칙 (필수 강제)]
1. **💻 로컬 툴**:
   - 사용자가 PC에서 선택한 실제 영상 파일명 및 절대 경로를 FFprobe로 추출하여 XML 내부에 정확히 일치시켜 기록.
   - 프리미어 프로 및 다빈치 리졸브로 XML 드래그 시 **재연결(Relink) 작업 없이 3초 만에 원본 영상 자동 인식**.
2. **⚡ 디스코드 봇**:
   - 치지직 VOD 메타데이터 기반으로 `[방송날짜]_[방송제목].xml` 생성 (예: `20260826_양망두_합방.xml`).
   - **다빈치 리졸브 미디어 오프라인 방지 필수 강제 안내**:
     > ⚠️ **[필수 안내]** 다빈치 리졸브(DaVinci Resolve) 및 프리미어 프로에서 타임라인이 정상적으로 열리려면, 소장하신 VOD 영상 파일명을 생성된 XML과 동일하게 **`[방송날짜]_[방송제목].mp4`로 반드시 변경**해 주셔야 합니다. (파일명이 다를 경우 다빈치 리졸브에서 영상을 인식하지 못합니다.)

## 6. 클라우드 디스코드 봇 통합 크레딧 과금 및 명령어 권한 체계

### 6.1. 과금 정책
- **화이트리스트 스트리머**: Modal GPU 자원 보호를 위해 **1일 2회 무료** 제공, 3회차부터는 **보유 크레딧**에서 1회당 1크레딧 차감하여 계속 이용 가능.
- **일반 사용자**: 1회 가편집 시 **1 크레딧** 충전 방식으로 이용.
- **결제 연동 API**: `POST /api/credit/add` (웹 결제 사이트 자동 충전 지원).

### 6.2. 명령어 권한 체계 (일반 사용자 vs 관리자 분리 & 숨김 처리)
